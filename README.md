# پیام‌بین (PayamBin)

اپ اندرویدی که روی گوشی یک وب‌سرور کوچک داخل شبکه بالا می‌آورد تا پیامک‌ها و اعلان پیام‌رسان‌ها را در مرورگر کامپیوتر ببینید و از همان‌جا پیامک بفرستید.

## امکانات
- **پیامک‌ها:** فهرست گفتگوها با نام مخاطب، تعداد خوانده‌نشده، تاریخ شمسی و جستجو در متن همهٔ پیام‌ها
- **ارسال پیامک** از کامپیوتر (Ctrl+Enter)، انتخاب سیم‌کارت در گوشی‌های دو سیم، شمارش تعداد پیامک
- **اعلان‌ها:** پیام‌های بله، تلگرام، واتساپ، ایتا، روبیکا و … (از طریق دسترسی اعلان‌ها)، با فیلتر برنامه
- کدهای ۴ تا ۸ رقمی (رمز پویا، کد تأیید) با یک کلیک کپی می‌شوند
- صدای هشدار و شمارنده در عنوان تب هنگام رسیدن پیام جدید
- ورود با رمز ۶ رقمی؛ فقط دستگاه‌های داخل شبکه (192.168.x / 10.x / 172.16-31.x) اجازهٔ اتصال دارند؛ قفل یک‌دقیقه‌ای بعد از ۵ رمز اشتباه
- روشن شدن خودکار بعد از ری‌استارت گوشی

## ساخت APK با GitHub Actions
1. یک مخزن جدید در گیت‌هاب بسازید (پیشنهاد: **Private**، چون کلید امضای برنامه داخل مخزن است).
2. محتوای این پوشه را push کنید:
   ```
   git init
   git add .
   git commit -m "PayamBin"
   git branch -M main
   git remote add origin https://github.com/<USER>/PayamBin.git
   git push -u origin main
   ```
3. در زبانهٔ **Actions** بیلد خودکار اجرا می‌شود (حدود ۳-۴ دقیقه). فایل `PayamBin.apk` در بخش **Releases → latest** و همچنین در Artifacts همان اجرا قرار می‌گیرد.

## راه‌اندازی روی گوشی
1. APK را نصب و برنامه را باز کنید؛ سرور خودبه‌خود روشن می‌شود.
2. دکمهٔ «دادن مجوز پیامک…» را بزنید و همه را تأیید کنید.
   - اگر اندروید ۱۳ به بالا مجوز را خاکستری نشان داد: **تنظیمات ← برنامه‌ها ← پیام‌بین ← منوی ⋮ ← Allow restricted settings** و دوباره امتحان کنید.
3. برای پیام‌رسان‌ها: «دسترسی به اعلان‌ها» ← پیام‌بین را روشن کنید.
4. «جلوگیری از بسته شدن توسط بهینه‌ساز باتری» را بزنید. در شیائومی/پوکو: Autostart روشن و Battery saver روی **No restrictions**.
5. آدرسی که روی صفحه است (مثل `http://192.168.1.34:8080`) را در مرورگر ویندوز باز کنید و رمز ۶ رقمی را وارد کنید.

> نکته: برای اینکه آدرس گوشی عوض نشود، در تنظیمات مودم برای گوشی **IP ثابت (DHCP Reservation)** تعریف کنید.

## محدودیت‌ها
- پیام‌های MMS (تصویری) نمایش داده نمی‌شوند؛ فقط پیامک متنی.
- اعلان پیام‌رسان‌ها فقط از زمانی که دسترسی اعلان فعال شده ذخیره می‌شوند (تاریخچهٔ قبلی را نمی‌توان خواند) و آخرین ۱۰۰۰ اعلان نگه داشته می‌شود.
- اگر فایروال/مودم «AP Isolation» یا «Client Isolation» داشته باشد، کامپیوتر به گوشی وصل نمی‌شود؛ آن را در تنظیمات مودم خاموش کنید.
- کلید امضا: `app/payambin.jks` (رمز `payambin123`). اگر مخزن عمومی است، بهتر است کلید را عوض کنید.

## ساختار
- `WebServer.java` – سرور HTTP بدون کتابخانهٔ جانبی، API و احراز هویت
- `SmsRepo.java` – خواندن/جستجو/ارسال پیامک، نام مخاطب، سیم‌کارت‌ها
- `NotifListener.java` / `NotifStore.java` – دریافت و نگهداری اعلان‌ها
- `ServerService.java` – سرویس پیش‌زمینه، WakeLock و WifiLock
- `assets/index.html` – رابط وب فارسی
